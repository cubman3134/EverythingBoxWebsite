## Nothing is configured for you

EverythingBox arrives empty on purpose. It ships no media, no games, no BIOS files, and it is not
pointed at any source. What it shows you is what you give it.

## Pick a theme

Two themes ship with the app and you can switch between them whenever you like:

- **Channels** — your library as a wall of bright tiles, with a clock and everything one press away.
- **Triple** — a dark cross-media bar. Categories run across the top, the active one drops down,
  and artwork for whatever you are on fills the right-hand side.

More install from the theme gallery, which you can open from **Settings → Appearance**. A theme is
a JSON file — colours, layout and artwork — so you can edit one to taste or write your own.

Neither theme changes what the app can do, only how it looks and how you move around it.

## Everything works with a remote

The whole interface is navigable with a D-pad, which is what makes the app usable on a television.
A keyboard, a mouse, a game controller and a TV remote are all first-class.
