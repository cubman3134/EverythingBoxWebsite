## macOS refuses to open it

The build is unsigned. Right-click the application and choose **Open**, then confirm. A
double-click will keep being refused until you have done this once.

## A game will not start

Three usual causes, in order of likelihood:

- **The file is not on this machine.** A library entry showing **Download** rather than **Play** is
  a catalog entry whose ROM you do not have yet. Nothing will boot until the file is on disk.
- **The core is missing.** Cores download on demand, so the machine needs network access the first
  time you open a given system.
- **The dump is wrong.** Some systems are strict about the file being a correct dump. A file that
  plays elsewhere but not here is usually a format the core does not accept rather than a fault in
  the app.

Systems needing BIOS files will not run without them. EverythingBox does not supply them; there is
a **BIOS Check** screen in settings that tells you which ones are missing.

## No artwork, just filenames

The catalog addon needs your own API keys. See [Artwork and metadata](/docs/metadata).

## A video plays with no sound, or the wrong track

Files with multiple audio tracks default to the first. Switch tracks from the playback controls.

## Subtitles are out of sync

Each file has its own subtitle offset. Adjust it during playback and the setting is remembered for
that file.

## Still stuck?

Most questions are not bug reports, and an issue thread is a poor place for a conversation. For
setup problems, "is this supposed to happen?", which core to use, or help writing an addon:

- **[Discord](https://discord.gg/bW7KMVhgwH)** — ask in `#support`. Say which platform you are on
  and which area (video, audio, emulation, addons, themes, readers); a vague question gets a vague
  answer. `#announcements` carries every release.
- **[r/EverythingBox](https://www.reddit.com/r/EverythingBox/)** — slower and searchable, so it is
  the better place for a question whose answer the next person should be able to find.

A **reproducible bug** or a feature proposal does belong in an
[issue](https://github.com/cubman3134/EverythingBox/issues). Say which platform and which version
you are on — the version is shown on the [download page](/download) and in settings.
